# Chris Newman

A responsive, dependency-free personal website for Chris Newman.

## Preview

Open index.html in a browser, or run:

    python3 -m http.server 8765

Then visit http://localhost:8765.

## Edit

- index.html: biography, section copy, navigation, metadata
- profile.css: active profile layout, typography, colors, and responsive styling
- styles.css: previous editorial design (not loaded by the current page)
- favicon.svg: browser icon

The employer is intentionally unnamed. The site includes the supplied LinkedIn link, but no email, phone number, external tracking, or unverified employment history. The current design uses a desktop profile sidebar and stacked mobile layout.

This site requires no build step and can be hosted on any static web host. Domain configuration and publishing are not included.
